# 夺帅 · 青石征途

[开始游戏](https://qw1281065768.github.io/commander-camp/)

排兵布阵、斩将过关。英雄、兵种、阵型与随机军策组成每次出征的搭配。

v4.0：六场军营试炼逐步开放兵种、英雄、阵型和海克斯，再进入五战分支征途。每段三选二，包含救援与精英；战后选择军策，失败可调整重试、换路或带回已获得的军功。

3 名英雄、4 类兵种、4 种阵型、10 枚实效军策；营地提供兵营训练、英雄修习与新选项解锁。点击编号编队换兵，换兵保留位置，主动选择阵型才重新排位。支持手机和桌面浏览器。

进度保存在当前浏览器。不同设备、本地试玩与线上地址的存档不自动互通。新版本使用独立存档，旧进度保留；在地址后添加 ?legacy=1 可进入旧玩法。

本仓库保存 Canvas 浏览器试玩版的发布文件，通过 GitHub Pages 部署；不是 Cocos 构建，也不包含微信开发者工具项目。
