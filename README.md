# 夺帅 · Commander Camp

[开始游戏](https://qw1281065768.github.io/commander-camp/)

排兵布阵、斩将过关。二十关主线、三军接力、武将技能树、兵营训练与挂机军功。

v3.2：从十二名士兵开始，五战攻下青石关。在战场上招募援军、选择主将、整备路线与阵型；金色按钮推进当前一步。首征后开放完整营地，保留旧存档。

点击编队换兵，点击主将换人；选择阵型后自动交战。支持手机和桌面浏览器。

进度保存在当前浏览器。不同设备、本地试玩与线上地址的存档不自动互通。

本仓库保存浏览器可玩版的发布文件，通过 GitHub Pages 部署；不包含微信开发者工具项目。
